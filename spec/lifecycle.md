# ユーザー定義型の寿命

コンストラクタは型名と同じ名前で、デストラクタは `~` に型名を続けて宣言します。どちらも戻り値型を指定しません。コンストラクタは引数の型によってオーバーロードできます。デストラクタには引数を指定せず、型ごとに一つだけ定義できます。アクセス修飾子は両方に適用されます。

暗黙のデフォルトコンストラクタは生成しません。コンストラクタを宣言していない型では、従来の `Type x {}` による集成体初期化を使えます。コンストラクタがある型の `Type x {}` は、明示的な引数なしコンストラクタが存在し、アクセス可能な場合にそれを呼び出します。

コンストラクタの本体では、そのオブジェクトの不変フィールドを含めて初期化できます。デストラクタへのアクセスは自動破棄の場合にも検査します。

コンストラクタの引数は左から右へ評価し、その後フィールドを宣言順に初期化してから本体を実行します。コンストラクタを持つメンバに明示的な初期値がない場合は、アクセス可能な引数なしコンストラクタを呼びます。存在しなければエラーです。

自動オブジェクトはスコープを離れるときに構築の逆順で破棄し、一時オブジェクトは式の終わりに破棄します。メンバオブジェクトは所有オブジェクトのデストラクタ本体の後、宣言の逆順に破棄します。

デストラクタを持つ型、およびそのような型を含む型のコピーは許可しません。一時オブジェクトは不変として扱います。破棄が必要なグローバル変数はエラーです。

破棄が必要な型は `return Type(...);` で返却先に直接構築できます。名前付きローカルの返却によるコピーは許可しません。値引数には直接構築した値または関数の返却値を渡せます。引数領域で構築し、呼び出し先で一度だけ破棄します。

値を返すブロック式や `if` 式では、各分岐で直接構築した値や関数の返却値を使えます。結果は変数、フィールド、値引数にも直接構築されます。名前付きオブジェクトのコピーは許可しません。
