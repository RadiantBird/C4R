# 制御構文

C4Rの制御構文は、値を要求された場合は「式」として扱われ、
そうでない従来の使い方（値を要求しない場合）は「文」として扱われます。

`return`は、現在評価している値スコープを終了して値を返します。

## 例

```cpp
int32 foo() {
    if (error) {
        return -1;
    }

    return 10;
}
```

`if (error)`は値を要求されていないため「文」です。

そのため、この`return`は`foo()`の戻り値として解釈され、
`error`が真の場合、`foo()`は`-1`を返します。

```cpp
int32 n = 1;

int32 x = if (n == 0) {
    return 2;
} else {
    return 4;
};
```

この`if`は代入式の右辺にあり、値を要求されているため「式」です。

そのため、内部の`return`は関数からではなく、現在評価している`if`式から値を返します。

この例では`n != 0`なので、`x`には`4`が代入されます。
