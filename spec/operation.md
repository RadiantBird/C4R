# 演算子

C4Rは、基本的な演算子についてC/C++に近い構文を採用します。

ただし、一部の演算子は追加・変更されています。

主な追加要素は以下です。

- べき乗演算子 `` ` ``
- 論理XOR `^^`
- NAND `!&&`
- NOR `!||`
- 連鎖比較

---

## 算術演算子

| 演算子 | 意味 |
| ---- | ---- |
| `a + b` | `a`と`b`を加算する |
| `a - b` | `a`から`b`を減算する |
| `a * b` | `a`と`b`を乗算する |
| `a / b` | `a`を`b`で除算する |
| `a % b` | `a`を`b`で割った余りを返す |
| ``a ` b`` | `a`を`b`乗する |

```cpp
int32 x = 2 + 4 * 3;
int32 y = 2 ` 8;
```

この場合、`y`は`256`になります。

---

## 単項演算子

| 演算子 | 意味 |
| ---- | ---- |
| `+a` | 正符号 |
| `-a` | 符号反転 |
| `!a` | 論理NOT |
| `~a` | ビット反転 |

```cpp
int32 x = -10;
bool enabled = !disabled;
```

## インクリメント・デクリメント

| 演算子 | 意味 |
| ---- | ---- |
| `a++` | `a`を1増加させる |
| `a--` | `a`を1減少させる |
| `++a` | `a`を1増加させる |
| `--a` | `a`を1減少させる |

```cpp
i++;
--count;
```

---

## 比較演算子

| 演算子 | 意味 |
| ---- | ---- |
| `a == b` | `a`と`b`が等しい |
| `a != b` | `a`と`b`が等しくない |
| `a < b` | `a`が`b`より小さい |
| `a > b` | `a`が`b`より大きい |
| `a <= b` | `a`が`b`以下 |
| `a >= b` | `a`が`b`以上 |

比較演算子は`bool`値を返します。

```cpp
bool adult = age >= 18;
```

---

## 連鎖比較

C4Rでは比較演算子を連鎖させることができます。

```cpp
if (18 <= age <= 130) {
    "Welcome!\n";
}
```

これは数学的な比較と同じ意味を持ちます。

```cpp
18 <= age && age <= 130
```

と同等です。

より長い比較も可能です。

```cpp
if (a < b < c < d) {
    return true;
}
```

各値は比較のために必要な回数だけ評価されます。

## 論理演算子と連鎖比較でエレガントに

AND、OR、NOTだけでも論理演算は記述できますが、複雑な条件では冗長になりやすく、条件式の意図が分かりにくくなることがあります。

C4RではNAND、NOR、XORも直接使用できます。

| 演算子 | 意味 |
| ---- | ---- |
| `&&` | AND |
| `\|\|` | OR |
| `!` | NOT |
| `!&&` | NAND |
| `!\|\|` | NOR |
| `^^` | XOR |

### AND

両方が真の場合に真になります。

```cpp
if (isAlive && isHuman) {
    return true;
}
```

### OR

どちらか一方以上が真の場合に真になります。

```cpp
if (hasKey || isAdmin) {
    open();
}
```

### NOT

真偽値を反転します。

```cpp
if (!isDead) {
    live();
}
```

### NAND

ANDの結果を反転します。

```cpp
a !&& b
```

は、

```cpp
!(a && b)
```

と同等です。

```cpp
if (wantFood !&& wantSleep) {
    "Go to bed <3\n";
}
```

### NOR

ORの結果を反転します。

```cpp
a !|| b
```

は、

```cpp
!(a || b)
```

と同等です。

### XOR

どちらか片方だけが真の場合に真になります。

```cpp
if (isAdmin ^^ isUser) {
    "YOU ARE AN HACKER!!\n";
}
```

真理値表は以下のようになります。

| `a` | `b` | `a ^^ b` |
| ---- | ---- | ---- |
| false | false | false |
| false | true | true |
| true | false | true |
| true | true | false |

## ビット演算子

整数型に対してビット単位の演算を行います。

| 演算子 | 意味 |
| ---- | ---- |
| `a & b` | ビットAND |
| `a \| b` | ビットOR |
| `a ^ b` | ビットXOR |
| `~a` | ビット反転 |
| `a << b` | 左シフト |
| `a >> b` | 右シフト |

論理XORには`^^`、ビットXORには`^`を使用します。

```cpp
bool x = a ^^ b;
int32 y = flags ^ mask;
```

| 演算子 | 意味 |
| ---- | ---- |
| `=` | 代入 |
| `+=` | 加算して代入 |
| `-=` | 減算して代入 |
| `*=` | 乗算して代入 |
| `/=` | 除算して代入 |
| `%=` | 剰余を求めて代入 |
| `&=` | ビットANDして代入 |
| `\|=` | ビットORして代入 |
| `^=` | ビットXORして代入 |
| `<<=` | 左シフトして代入 |
| `>>=` | 右シフトして代入 |

```cpp
x += 10;

```

## 括弧

`()`を使用することで、演算順序を明示できます。

```cpp
int32 x = (2 + 4) * 3;
```

括弧内の式は、外側の演算より先に評価されます。

---

## 演算子の優先順位

演算子には優先順位があります。

優先順位が高い演算子ほど先に評価されます。

```cpp
a + b * c
```

は、

```cpp
a + (b * c)
```

として解釈されます。

括弧を使用した場合は、括弧内が優先されます。

```cpp
(a + b) * c
```

C4R独自の演算子を含めた完全な優先順位表は以下の通りです。

| 優先度 | 演算子 | 種類 |
| ---- | ---- | ---- |
| 高 | `()` `[]` `.` `->` | 呼び出し・アクセス |
|  | `++` `--` | インクリメント・デクリメント |
|  | `!` `~` 単項`+` 単項`-` | 単項演算 |
|  | `` ` `` | べき乗 |
|  | `*` `/` `%` | 乗除算 |
|  | `+` `-` | 加減算 |
|  | `<<` `>>` | シフト |
|  | `<` `<=` `>` `>=` | 比較 |
|  | `==` `!=` | 等価比較 |
|  | `&` | ビットAND |
|  | `^` | ビットXOR |
|  | `\|` | ビットOR |
|  | `&&` | 論理AND |
|  | `^^` | 論理XOR |
|  | `\|\|` | 論理OR |
|  | `!&&` | NAND |
|  | `!\|\|` | NOR |
| 低 | `=` `+=` `-=` `*=` `/=` `%=` `&=` `\|=` `^=` `<<=` `>>=` | 代入 |

括弧を使用すれば、優先順位に関係なく評価順を明示できます。

```cpp
bool result = (a || b) && c;
```
