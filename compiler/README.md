# C4R コンパイラ

`builder.ps1 build` で `build/Debug/c4rc.exe` をビルドします。

```powershell
c4rc -i main.c4r math.c4r -o app.exe
```

`-i` / `--input` は複数ファイルを受け取り、繰り返して指定できます。指定されたファイルだけを一つのコンパイル単位として扱います。`-o` / `--output` を省略すると、単一ファイルではソースと同じ名前の `.exe`、複数ファイルではカレントディレクトリの `app.exe` を出力します。`-h` / `--help` で使い方、`-v` / `--version` でコンパイラのバージョンを表示します。

複数ファイルのプログラムには明示的なエントリーポイントが一つ必要です。グローバル変数の初期値は定数式に限られます。単一ファイルでは従来の暗黙エントリーポイントも使えます。

エディター連携用の `--check` と `--symbols` も引き続き利用できます。
