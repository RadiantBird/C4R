# C4R Language

VS Code で `vscode-extension` フォルダーを開き、F5 を押して拡張機能開発ホストを起動します。`.c4r` ファイルを開くと、コンパイラの `--check -` に編集中の内容を渡して診断します。

既定ではワークスペース、編集中のファイル、拡張機能のフォルダーから親方向に `compiler/build/Debug/C4R.exe` を探します。別の場所にある場合は `c4r.compilerPath` に実行ファイルの絶対パス、またはワークスペースからの相対パスを設定してください。コンパイラを先に `compiler/builder.ps1 build` でビルドする必要があります。

チェックはオブジェクト生成やリンクを行わず、最初のエラーを表示します。現在、構文エラーの位置はトークン単位ですが、意味解析エラーの位置は式や文の開始位置になる場合があります。コンパイラを起動できない場合は「出力」の C4R チャンネルを確認してください。

補完とホバーの型表示はコンパイラの `--symbols` を使用します。編集中の不完全なコードにも対応するため、この問い合わせはカーソルより前の宣言から候補を推定します。スコープや capture の厳密な検証は `--check` が行います。
